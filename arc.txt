CRM для IT-компании (например, управление проектами и задачами)
Сущности и связи:

Client — клиенты

Project — проекты (принадлежат клиенту)

Task — задачи (принадлежат проекту, имеют исполнителя)

User — сотрудники (менеджеры, разработчики)

TimeEntry — списание времени по задачам

Invoice — счета (создаются на основе проектов)

Сложные связи:

Полиморфные теги / комментарии

Многие ко многим (сотрудники могут работать на нескольких проектах)

Вложенные ресурсы (Project → Tasks через RelationManager)

Триггеры/события:

При закрытии задачи → проверяется, все ли часы списаны

При завершении всех задач проекта → проект автоматически закрывается

WebSockets:

Новая задача → уведомление исполнителю в реальном времени

Вложенные запросы:

Дашборд с суммой часов по проектам, загрузкой сотрудников

Логика связей для CRM:
text
Client (1) —— (m) Project
Project (1) —— (m) Task
Task (1) —— (m) TimeEntry
User (1) —— (m) Task (как исполнитель)
Project (1) —— (1) Invoice

clients → projects (один ко многим)

projects → tasks (один ко многим)

tasks → time_entries (один ко многим)

projects → invoices (один к одному)

users → tasks (как исполнитель)
